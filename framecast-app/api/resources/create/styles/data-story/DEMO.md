# Data story: the worked example

A 15 s results video for Brewline, a sample coffee loyalty app used only as an example (source in style-example/). Its figures belong to that sample; never reuse them. Learn the technique; do not repeat it.

- Structure: three figures, each its own beat (a percentage, a member count, a before-and-after), then the brand.
- Opening: the headline percentage counting up, huge, with its label above.
- Signature shot: the before-and-after bars, the new value growing taller in the accent colour.
- Camera path: static grid on a warm paper field; motion comes from counters, bars and a dot grid filling.
- Score shape: silent build.
- Ending: the brand name with one descriptive line.

Weak spot to beat: the closing 3 s hold an empty ring and the name; end on the meaning or the offer, with motion.

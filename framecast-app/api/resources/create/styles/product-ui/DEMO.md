# Product UI build: the worked example

A 15 s WyvStudio product video (example source in style-example/). Learn its technique; do not repeat it.

- Structure: five beats on one continuous surface: empty input, idea typed, generate pressed, a voiced and captioned preview, the preview splitting into four formats, brand close.
- Opening: an empty input field with a blinking caret under a headline.
- Signature shot: the preview window splits and reflows into four format frames, each ticked.
- Camera path: a gentle push into the input, then a pull back to the full grid.
- Score shape: silent build.
- Ending: centred brand mark, name and call to action with one benefit.

Weak spot to beat: the first 4 s are nearly static (an empty field and a moving cursor). Open on motion or the result, inside 2 s.

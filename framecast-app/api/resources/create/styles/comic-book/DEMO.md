# Comic book: the worked example

A 15 s vertical feature announcement for Tickly, a sample to-do app used only as an example (source in
style-example/), told as a three-panel comic. Its copy belongs to that sample; never reuse it. Learn the technique;
do not repeat it.

- Structure: buried in notifications, CLICK! on the focus button, calm with "Focus mode is here!", then the whole page and the brand.
- Opening: the camera is inside panel 1 as the notifications pile up around the worried character.
- Signature shot: the CLICK! burst stamping as the finger presses the button, and the badges vanishing.
- Camera path: panel 1, panel 2, panel 3, pull back to the page.
- Ending: the full page with TICKLY and the call to action.

Weak spot to beat: the character barely acts in panel 3; give the calm moment a real gesture.

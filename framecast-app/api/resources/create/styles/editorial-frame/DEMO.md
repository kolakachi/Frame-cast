# Editorial frame: the worked example

A 15 s WyvStudio explainer (example source in style-example/). Learn its technique; do not repeat it.

- Structure: five numbered beats (01 / 05 to 05 / 05): problem, what it does, why it is easy, formats, close.
- Opening: the problem drawn, not said: a camera icon above a cluttered editing timeline, then a line strikes the camera out.
- Signature shot: hard cuts between near-black, orange and cream fields, with the corner labels and beat number changing on each cut.
- Camera path: static frame; all motion is inside the grid.
- Score shape: silent build.
- Ending: the wordmark alone with an underline on near-black.

Weak spot to beat: the formats beat is four empty outlined frames sitting still; give every beat an event.

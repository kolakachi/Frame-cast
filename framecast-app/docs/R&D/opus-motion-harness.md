# Opus 5.5 Motion Design Harness (field guide, Oct 2026)

An independent guide: a gated prompt for Claude Code plus Mortiflix (GTKottman/mortiflix-oss), a harness that enforces
the rules in code. Pipeline: brief → script + style frames → transitions → animatic → music → build → final, with the
owner approving every gate and 12 checks reported before each one. A 5 s logo sting cost about $3.52 on Opus 5.5.

## Where Create already matches it
Gates (plan card, character and storyboard steps, the look stills on Thorough); approved script and copy locked; rules
in code (final checks block delivery and send repairs); safe areas, collisions, contrast; script length and reading
time; sync to key words; −14 LUFS; runaway guards (budget, balance, no progress); resumable builds.

## To take
- **Every cut has a carrier** (next): each transition names what carries the eye (a shape, a line, a camera move),
  why, and the word it lands on; crossfade only when nothing better connects the ideas. A plan rule plus a check.
- **True peak ≤ −1 dBTP** beside −14 LUFS (next): one line in the loudness step.
- **Answer every change note** (idea): the next version lists each note with exactly what changed, never "addressed".
- **Misses become checks** (idea): a defect the checks missed proposes a new check; approved once, it runs on every
  video. Our style verdicts are the softer version.
- **Original music as code** (idea): Strudel scores, deterministic, free, no licence questions.
- **Studio mode** (idea): a gate at every stage for agencies who want it; too many stops as the default.

# Deliver approved work

Open **Delivery** after the relevant exports have been approved.

[![Delivery builder with an approved export, supporting files and link expiry](/img/howto/clients-delivery-guide.png)](/img/howto/clients-delivery-guide.png)

*Select a screenshot to view it at full size. Screenshots use illustrative demo data.*

## Build the package

1. Enter a **Package title**, such as “Acme September launch”.
2. Add a **Handoff note** explaining the contents and intended placements.
3. Select the **Approved video versions**. Check the project, aspect ratio and export number.
4. Upload or select any **Supporting files**, such as captions, thumbnails or source files. These must be attached deliberately; the app does not promise to generate every supporting file automatically.
5. Set **Link expires in days**, from 1 to 90.
6. Click **Create delivery link**, then **Open** it to verify the package before using **Copy link**.

Send the copied link through your normal communication channel. Creating or copying a link is not the same as sending it to the client.

## What the recipient sees

[![Recipient delivery page with the package, expiry and file links](/img/howto/clients-recipient-guide.png)](/img/howto/clients-recipient-guide.png)

The recipient opens or downloads each file. If an individual download link expires while the package is still available, use **Refresh links** on the delivery page.

## Expired or revoked links

The recipient page stops working when the link expires or you revoke it. Use **Revoke** on the package if access should end early. Download links already issued can remain usable for up to ten minutes; revocation does not remove files someone already downloaded.

Create a new delivery link when an expired package needs to be shared again. If you revised the video, export and approve the replacement first, then select that version in a new package. Previously delivered files do not update automatically.

# Create & apply brand kits

A **brand kit** is a reusable preset of colors, fonts, and a default voice. Apply it to a channel or a project and everything you make stays on-brand.

## What a brand kit holds

- **Name** — e.g. "Finance Authority".
- **Brand colors** — Primary, Secondary, and Accent (as a picker or hex).
- **Fonts** — a Primary and Secondary font from the built-in set (DM Sans, Space Mono, Fraunces, Sora, Archivo, Bricolage Grotesque, Outfit, Manrope, Playfair Display, IBM Plex Sans).
- **Default voice** — the voiceover applied to new scenes.

## Create or edit a brand kit

Brand kits live in **Settings → Brand Kits**:

1. Pick an existing kit from the grid, or click **+ New Kit**.
2. Set the name, colors, fonts, and default voice.
3. Click **Save Brand Kit** (or **Create Brand Kit** for a new one).

## Where brand kits apply

- On a [channel](/channels/create-a-channel) — set as its default brand kit.
- In the [editor](/the-editor/brand-kit-and-hooks) — apply a kit to the current project.

## Delete a brand kit

Open the kit and choose **Delete Brand Kit**, then confirm. Channels using it will need a new default kit.

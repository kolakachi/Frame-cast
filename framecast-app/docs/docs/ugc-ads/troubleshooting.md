# UGC troubleshooting

| What you see | What to do next |
|---|---|
| A product URL cannot be read | Paste confirmed product facts into the brief and continue from an idea or script |
| A reference video cannot be understood | Confirm the selected file is playable; try a shorter relevant source or describe its structure in the brief |
| A video is rejected by a product-photo slot | Use still images there; select video through the footage controls |
| The selected face cannot be used | Choose the saved-character path where supported, or an invented presenter; changing a portrait to an AI-generated photorealistic face is not a guaranteed solution |
| The take needs a retry | Open its progress/details, read the error and use the offered retry action; do not repeatedly create new takes |
| The estimate changed | Review the current plan and price and approve again |
| There are credits but generation is blocked | Check plan eligibility, monthly take allowance and any client spending cap |
| A revision is still running | Wait for completion before submitting another revision or exporting |
| Download, sharing or scheduling is unavailable | Finish generation/revision and complete an export first |
| The download contains the old version | Export again after the latest revision |

If a model declines a take, preserve the error message. Retry guidance depends on the failing input and engine; repeated unchanged attempts may fail again.

When contacting support, include the take/project ID, the action you attempted, the exact error, the approximate time, and whether it was a new take, retry, revision or export. Do not include account passwords or private payment information.

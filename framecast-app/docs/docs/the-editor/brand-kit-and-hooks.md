# Brand kit & hooks

The **Brand Kit** section (bottom of the Config panel) ties a project to a channel and a set of brand defaults, and lets you generate alternate hooks.

## Apply a brand kit

- **Channel** — associate the project with a [channel](/channels/create-a-channel).
- **Brand Kit** — apply a [brand kit](/brand-kits/create-and-apply-brand-kits) (colors, fonts, default voice).
- **Save Defaults** — save these as the project's defaults.

Applying a channel can prefill the brand kit for future changes. Existing scenes aren't rewritten automatically — it sets the defaults going forward.

## Generate hooks

When your video has a script, the **Hook options** block can generate ranked opening lines:

- **✨ Generate hooks** (or **↻ Regenerate**) — produces scored hook candidates. This doesn't cost credits.
- **Use Hook** — apply a hook to your video.

A strong hook is the single biggest lever on short-form retention, so it's worth trying a few. For a deeper workflow, see [Generate hook variants](/variants-and-hooks/generate-hook-variants).

# Project settings & script

The top two sections of the **Config** panel cover your project name and the selected scene's script.

## Project Settings

- **Name** — click the project name to rename it inline; it saves when you click away.
- **Aspect Ratio** — shown here for reference. You choose which ratios to render when you [export](/the-editor/export-share-and-schedule).

## Scene Script

The **Scene Script** section controls the selected scene's narration:

- **Script** — the words spoken by the voice and rendered as captions. Edit freely.
- **Duration** — how long the scene runs (used when no voice is generated).

If you change the script after generating a voice, a **Voice outdated** badge appears — regenerate the voice from the [Voice](/the-editor/voice) section to match.

### Rewrite with AI

Open **Rewrite with AI** to have the assistant rework just this scene's line:

- **Edit** — Shorten, Expand, Simplify, or Stronger hook.
- **Tone** — Punchier, Dramatic, Scarier, Documentary, or Educational.
- **Custom instruction** — type your own direction.

You'll get an **AI Rewrite Candidate** you can **Accept** or **Reject**. Locked facts are preserved, and the change applies to this scene only.

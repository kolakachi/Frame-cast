# Style your captions

The **Captions** section styles the on-screen text. Captions are drawn from each scene's script, and caption styling applies to **all scenes** so your video stays consistent.

## Turn captions on

Toggle **On** at the top of the section. You can save a look as a **preset** and re-apply it later with **+ Save as preset**.

## Caption effects

Pick how the words arrive on screen. **Plain** is the default — captions
appear with no animation, exactly as they always have. Every other effect
animates, and each one renders identically in the editor preview and in the
exported video.

| Effect | What it does |
| --- | --- |
| **Plain** | No animation. The original look. |
| **Karaoke** | Each word lights up as it's spoken. |
| **Beast** | Big bold words punching in one at a time. |
| **Comic Pop** | Tilted, shearing words with a comic-book feel. |
| **Sticker** | Words land at a slight angle, like stuck-on labels. |
| **Box** | Each word inside a filled rounded box. |
| **Stream** | Text types itself out with a moving cursor. |
| **Blur In** | Words resolve from a blur. |
| **Glitch** | Colour-split judder on each word. |
| **Slide Up** | Words rise into place. |
| **Wave** | Words hop in sequence. |
| **Punch** | Hard scale-up on every word. |
| **Tracking** | Letter spacing tightens as the line lands. |
| **Neon** | Glowing outline that pulses on. |
| **News Bar** | Lower-third bar, broadcast style. |
| **Marker** | Highlighter sweeping behind the words. |

Every other caption setting still applies on top of whichever effect you
choose — font, size, colours, highlight mode and position all keep working.
Switching effects never resets them.

Click **View all** under Caption effect to see every option previewed on your
own text.

![the Caption effects picker showing all sixteen styles](/img/howto/editor-captions.png)

Some effects come with a backdrop panel behind the text (**Stream**, **News
Bar**). Tick **Backdrop panel behind text** to turn it on, and set its colour
with the panel colour swatch.

## Other style options

- **Base style** — Impact, Editorial, or Hacker. This is the underlying look of
  the text and is separate from the effect above; the effect controls how words
  arrive, the base style controls how they're set.
- **Highlight** — Keywords, Word-by-word, Line-by-line, or None.
- **Position** — Bottom third, Center, or Top third.
- **Font** — grouped by style (Bold Display, Sans-serif, Serif, Script, Mono, Handwritten).
- **Text color** and **Highlight color** — pick a swatch (white, yellow, orange, red, green, blue, purple, black) or a custom color.
- **Text size** — S, M, L, or XL.

## Apply to every scene

Changes preview on the current scene. Click **Apply to all scenes** to push the same caption style across the whole video. You'll see **✓ Applied to all scenes** when it's done.

# Set the voice

The **Voice** section of the Config panel controls the voiceover for the selected scene. It has two tabs: **Default** (a WyvStudio or cloned voice) and **Custom** (your own audio).

## Default voice

- **Preview** — hear the current voice, with its language and speed.
- **Volume** — 0–200% (default 100).
- **Speed** — 0.8×, 1.0×, 1.1×, or 1.2×.
- **Stability** — Low, Medium, or High.
- **Change ▾** — open the voice picker (below) to switch voices.
- **Voice direction** *(optional, expressive voices only)* — describe the delivery, and use inline cues like `[laughs]` or `[whispering]` in the script.

If you edit the script, a **Regenerate** prompt appears so the voice matches the new words. You can also **+ Save voice as profile** to reuse a configured voice.

### The voice picker

**Change ▾** opens **Select a voice**, grouped into:

- **Personalities** — Narrator, Teen girl, Teen boy, Child, Old man, Old woman, Hype, Calm. Each shifts the delivery of an expressive voice.
- **Your voices** — voices you've [cloned](/voice/clone-your-voice), with **＋ Clone a voice**.
- **Expressive voices** and **Standard voices** — the built-in library.

Preview any voice with ▶ and click **Use** to apply it.

![the Select a voice modal with the personality grid](/img/howto/editor-voice-picker.png)

## Custom voice

Use your own recording for a scene:

- **⬆ Upload** an audio file, or **● Record** directly.
- Preview it, then **✓ Use this audio** (or **↻ Redo**).
- Choose **Use voice + update script** (WyvStudio transcribes it into the script and captions) or **Use voice only**.

Previously uploaded clips are searchable so you can reuse them.

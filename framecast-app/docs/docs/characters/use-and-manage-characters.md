# Use & manage characters

## Test a character

Use the ✦ **Generate image** action on a character card to see how it renders before you use it in a video. You set:

- **Image model** *(when a reference exists)* — **Nano Banana Pro** (best identity, ~35 cr), **Nano Banana** (fast & cheap, ~10 cr), or **GPT Image 2** (~50 cr).
- **Scene prompt** — what the character is doing.
- **Style** — photorealistic, cinematic, documentary, anime, 3D animated, and more.
- **Aspect** — 9:16, 1:1, or 16:9.
- **Quality** — low, medium, or high.
- **Make this the primary reference photo** — every generated image joins the reference set; this checkbox controls which one is primary.

The estimated cost is shown before you generate.

![the test-image modal with model, style, and quality](/img/howto/character-generate.png)

## Use a character in a video

Characters are picked wherever you generate AI images:

- In the [New Video wizard](/make-a-video/from-a-brief) — attach a character on the content step.
- In [One-shot](/make-a-video/one-shot-prompt) — add a character as a reference.
- In the [editor's AI image tab](/the-editor/visual-source) — bind a character to any scene.

## Manage your library

- **Edit** — update the name, description, reference photos, or identity strength.
- **Delete** — remove a character with the ✕ action. Existing scenes keep their generated images; new scenes just can't pick it anymore.

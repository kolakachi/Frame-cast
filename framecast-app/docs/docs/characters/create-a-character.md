# Create a character

A **character** is a reusable identity — a name, a description, and reference photos — that lives across every project and series in your workspace. Pick one when generating AI images and the same person shows up consistently.

## Create a character

From **Characters**, click **＋ New Character** (or the create action) and fill in:

- **Reference image** *(optional)* — a PNG or JPG, up to 10 MB. The clearer the face, the better the likeness.
- **Name** *(required)*.
- **Description** *(optional)* — up to 2,000 characters. This is injected into scene prompts to keep the character consistent across episodes.
- **More reference photos** *(optional)* — up to 8 images; the first is the **primary** reference. Extra angles improve future results.
- **Likeness consent** — required whenever a reference photo is present, confirming you have the right to use that likeness.
- **Identity strength** — how closely generated images stick to the reference:
  - **Subtle** — looser drift.
  - **Balanced** — recommended (default).
  - **Strong** — sticks closer.
  - **Locked** — near-exact (can look plasticky on small references).

Save to add the character to your library.
